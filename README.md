# NULL VENTANA — User Guide

Null Ventana is a browser-based, audio-reactive visualizer and video mixer. Eight source layers — a live camera, two video files, a still image or 3D model, three generative shapes and a text overlay — are stacked bottom to top, each with its own mute (and, for all but the text, its own mix). Seventeen video effects sit in the same stack: every layer and every effect is a box you can drag, so an effect can work on the whole picture or only on the layers beneath it. Almost everything can be modulated by LFOs and by whatever is coming into the audio input. Output can be widescreen, square or vertical, and can be screenshotted, recorded to MP4, floated as a virtual-camera source, and saved in 100 preset slots that remember which video, image or model files were loaded.

Everything lives in one HTML file. Open it in a modern browser (Chrome or Edge recommended; Safari works; Firefox works but records WebM instead of MP4).

---

## 1. Quick start

1. Open `Null_Ventana.html` in your browser.
2. Open the **AUDIO INPUT** section, press **MIC ON** and allow microphone access. The header changes from OFF to the sensitivity percentage and the four band meters start moving.
3. Open **SHAPE A**, pick a shape from the dropdown, a palette under **COLOR PALETTE**, and drag that shape's **DENSITY** and **RATE OF CHANGE** to taste.
4. Press **F** for fullscreen and **Tab** to hide the panel.

Nothing is uploaded anywhere; audio, video and camera stay in the browser.

---

## 2. Layout and global controls

The control panel sits on the left. The canvas fills the rest of the window.

**The panel is the signal path, top to bottom.** The stack comes first — the layers in the order they are stacked (layer 1 at the bottom of the picture is at the top of the panel), with the effects among or after them — then the display filter, output and housekeeping. The stack starts in this order and can be rearranged (see **Stack order** below):

1. **CAMERA** — layer 1 (bottom)
2. **VIDEO FILE A** — layer 2
3. **VIDEO FILE B** — layer 3
4. **IMAGE** — layer 4
5. **SHAPE A** — layer 5
6. **SHAPE B** — layer 6
7. **SHAPE C** — layer 7
8. **TEXT OVERLAY** — layer 8 (top)
9. **The seventeen effects**, each in its own amber-edged box marked EFFECT, with its current value in the title: RESOLUTION, INK, RGB, ASCII, FOG, TRAILS, GLITCH, PAINT, POINTS, THRESHOLD, EDGES, CONTOUR, SMEAR, DITHER, HALFTONE, BLUR, FEEDBACK
10. **DISPLAY FILTER**
11. **COLOR PALETTE**, **OUTPUT GRADE**, **BACKGROUND**
12. **TRANSPORT** (pause, fullscreen, detach, reseed), **AUDIO INPUT** (mic, sensitivity, device, meters), **EXPORT**, **PRESETS**

Every source layer starts with a **MUTE** button, and every layer except the text overlay ends with a **MIX** slider. MUTE (red when on) silences that layer: it keeps running — the camera stream, video playback, grain loops and shape clocks all carry on — but nothing from it reaches the picture, so unmuting is instant. MIX is how much of the layer goes into the picture, over everything beneath it. There is no crossfader — set each layer's mix independently.

**Stack order**
- Drag any layer or effect box up or down by its title bar to change where it sits in the stack. The picture restacks as you drag and the **LAYER n** labels renumber. Each title has a dotted grip on its left; with a mouse you can grab anywhere on the title, on a touch screen use the grip. A plain click still opens and closes the box, and the panel scrolls when you drag near its top or bottom edge.
- The panel always reads top to bottom as bottom of the picture to top, so dragging a layer box **down** the panel moves that layer **up** the stack.
- **An effect works on everything above it in the panel and leaves everything below it alone.** In the starting order all seventeen effects sit below the eight layers, so each one treats the whole picture, in the order listed. Drag BLUR up to just above SHAPE A and TEXT OVERLAY and it blurs only the layers before it: the shape and the text are laid over the blurred picture, sharp.
- Effects can also be reordered among themselves: THRESHOLD before HALFTONE gives a different picture from HALFTONE before THRESHOLD.
- An effect at 0% is skipped entirely. Parking an unused effect among the layers costs nothing and changes nothing.
- Any order works: a shape under a keyed video, the image on top of the shapes, the text behind a shape, FEEDBACK under everything but the text. The video and image titles show the layer number and the loaded file name side by side.
- The order is saved in presets and mirrored in the detached panel. There is no reset button; drag the boxes back, or load a preset saved with the order you want. Presets saved before the effects could be moved load with the effects in their standard order.
- DISPLAY FILTER and OUTPUT GRADE are not part of the stack: they always come last.

**Panel behaviour**
- Every section header collapses when clicked. All sections start collapsed; click a header to open it.
- The panel stays up only while the mouse is over it and fades out the moment the mouse leaves the panel area (or the window). Move the mouse back over the strip on the left to bring it straight back. A key press or a touch shows it for a couple of seconds instead, since neither has a hover. The mouse cursor stays visible over the display.
- **DETACH ↗** (in TRANSPORT) pops the whole panel into its own window so the visuals can go fullscreen on one display while you drive them from another. Every control stays in sync in both windows. **ATTACH ↙** brings it back.
- **Double-click any slider** to reset it to its default.
- **Drag a layer or effect title** up or down to reorder the stack (see above).

**Keyboard**

| Key | Action |
|---|---|
| Tab | Hide / show the panel |
| Space | Pause / run — freezes the shapes, both video files and the camera |
| F | Fullscreen |
| R | New random seed |
| 1 – 9, 0 | Shape A, the first ten entries of the (alphabetical) shape list: 1 = OFF, 2 = 8-BIT : BREAKOUT, 3 = 8-BIT : MUNCH, 4 = 8-BIT : QUILT, 5 = 8-BIT : RIVER RUN, 6 = 8-BIT : SPRITES, 7 = SCENE : ALTITUDE, 8 = SCENE : CATHEDRAL, 9 = SCENE : CITY, 0 = SCENE : CLOUDS |

Shortcuts are ignored while you're typing in the text box or have a dropdown open, and whenever Cmd, Ctrl or Alt is held, so the browser's own shortcuts (reload, find, tab switching) are left alone.

**TRANSPORT**
- **PAUSE / RUN** — freezes everything that moves: shape time, both video files and the camera feed (a running camera grain loop picks up where it stopped).
- **FULLSCREEN** — same as F.
- **DETACH / ATTACH** — the pop-out panel, see above.
- **RESEED** — new random seed; generated shapes rebuild with a different layout (all three shape slots).
- **BEAT RESEED** — reseeds automatically on every detected kick. Turns the mic on if needed.

The **MIC ON/OFF** button lives in AUDIO INPUT (section 12).

## 3. Modulation: the MOD DEPTH / LFO RATE / AUDIO MOD groups

Most sliders — every effect, each layer's DENSITY, RATE OF CHANGE, ZOOM and MIX, the image's SIZE and a 3D model's zoom and two rotations — have a small indented group under them with three sub-sliders. These modulate the parent slider around its current value:

- **MOD DEPTH** (-100% … +100%) — how far an LFO swings the parameter. Negative values invert the swing. 0% = off.
- **LFO RATE** (0.02 Hz … 5 Hz) — speed of that LFO. Around 0.1 Hz is a slow breathe; 2–5 Hz is a flicker.
- **AUDIO MOD** (-100% … +100%) — how much the named audio band pushes the parameter. Each parameter listens to a specific band (shown in the label): BASS, LOW-MID, HIGH-MID or AIR. Negative values pull the parameter down when the band is loud.

LFO and audio modulation add together on top of the slider's own value, and the result is clamped to the slider's range.

## 4. Source layers 1–3: CAMERA, VIDEO FILE A, VIDEO FILE B

(Layer numbers in the section titles are the default order; drag the boxes to change it.)

The bottom three layers are live or recorded pictures. By default they are drawn beneath the shapes, and they pass through every effect placed after them in the stack, then the display filter, like everything else. A source that isn't running (camera off, no file loaded, deck stopped) simply drops out of the stack.

Each of the three sections has the same shape, top to bottom: MUTE, its own controls, GRANULAR RESET, an eight-slider grade (six tone controls plus tint), a KEY section, then MIX.

**CAMERA (layer 1 by default)**
- **MUTE**, **CAMERA ON/OFF** and a device selector.

**VIDEO FILE A (layer 2 by default) and VIDEO FILE B (layer 3 by default)** — two independent decks with their own file, play head, loop, grain, grade and key.
- **MUTE** — silence this deck without stopping it.
- **LOAD VIDEO** — choose a local file (anything the browser can play: MP4, WebM, MOV…). It starts playing immediately, muted; the file name shows in the header next to the layer number. In Chrome, Edge and other Chromium browsers the file is chosen through the browser's own picker so that a preset can open it again later (see PRESETS).
- **START / STOP** — STOP returns the play head to LOOP START.
- **LOOP** — repeat between LOOP START and LOOP END.
- **FILL SCREEN** — every source is already scaled to cover the screen, so if a clip still shows black bars they are baked into the file (letterbox or pillarbox). With FILL SCREEN on, the deck measures those bars from a small copy of the picture about once a second and zooms past them so the real image fills the display. It follows the grade, key and grain hold frame, and is saved in presets.
- **PLAY HEAD** — follows playback; drag to scrub. The readout shows time / duration.
- **LOOP START / LOOP END** — the region used by LOOP and by GRANULAR RESET. Labels switch from % to timestamps once a file is loaded. With LOOP off, playback stops at LOOP END.

**GRANULAR RESET** (per source, needs the mic)
Each of the three sources has its own GRANULAR RESET button and grain sliders, so the camera and both decks can be granular independently. On every detected beat a video deck jumps to a random point inside its LOOP START–END region and repeats a short random-length "grain" from there until the next beat; the camera loops the last slice (up to 2 s) of live footage from the moment of the beat. The trigger has its own detector that gets more sensitive when the input is loud, so busy passages fire on smaller hits.
- **GRAIN MAX LENGTH** — longest grain the loop can pick (0.1–8 s; the camera is capped at 2 s). Grains are always at least 0.15 s.
- **GRAIN CROSSFADE** — the frame before each jump or loop-wrap is held and faded out over the new picture so cuts don't flash (0 = hard cut, default 150 ms). Capped at half the grain length for very short grains.

**Grade** (per source)
- **EXPOSURE / TEMPERATURE / SATURATION / SHADOWS / MIDTONES / HIGHLIGHTS** — a colour grade applied to that source alone, before it is mixed (the held frames used by GRAIN CROSSFADE are graded too). Each source has its own grade, so the camera can be cool and desaturated while video B is warm. Everything at neutral costs nothing.
- **TINT COLOR / TINT AMOUNT** — a colour gel over this source alone: pick a hue (the readout takes on the colour) and how strongly the layer is pushed toward it. The tint is luma-normalised, so moderate amounts recolour without darkening. It is baked into the same per-source lookup as the grade, so it costs nothing extra.
- The same eight controls appear in OUTPUT GRADE for the whole picture.

**KEY** (per source)
A keyer like the one on a video mixer: the chosen colour or brightness is cut out of this layer and the layers beneath show through the hole.
- **OFF / CHROMA GREEN / CHROMA BLUE / LUMA BLACK / LUMA WHITE** — what to cut: green or blue, or the dark or bright areas.
- **INVERT KEY** — flips the key: the keyed colour or brightness is what stays and everything else goes transparent (e.g. CHROMA GREEN + INVERT keeps only the green parts of a clip).
- **KEY LEVEL** — how much is keyed out: low cuts only the pure key colour, high cuts a wide range around it.
- **KEY GAIN** — the edge of the key: low is soft and semi-transparent, high is a hard cut.
- The key runs on the GPU alongside the grade (with a per-pixel fallback in browsers without canvas filters). Typical uses: green-screen footage in VIDEO FILE B keyed green over VIDEO FILE A; the camera on LUMA BLACK so its dark areas open onto the palette background; a clip on LUMA WHITE + INVERT so only its highlights land on top of the shapes.

**MIX** (per source)
- How much of this layer goes into the output, over the layers below it. 100% covers what is beneath; lower values blend. Modulatable — an LFO on a video deck's MIX fades it in and out, AUDIO MOD pumps it on the beat.

## 5. Source layer 4: IMAGE (stills and 3D models)

A still picture or a 3D model, by default between the video decks and the shapes, always centred on the screen. The section, top to bottom:

- **MUTE** and **LOAD IMAGE / 3D MODEL** — any image the browser can show (PNG, JPEG, GIF, WebP…), or a 3D model in **USDZ** or **GLB** format. The file name shows in the header next to the layer number.
- **SIZE** (10–300%) — how big the image or the model's picture is on the display. 100% covers the screen; smaller sizes leave the layers beneath showing around it, larger sizes zoom into its middle. Modulatable: the MOD DEPTH / LFO RATE / AUDIO MOD (BASS) group under it lets it breathe on an LFO or swell on the kick (modulation can push it from 5% to 300%).
- **3D ZOOM** (10–400%) — for a model: how near the camera is. At 100% the whole model just fits the picture; higher moves in, lower moves away. AUDIO MOD: BASS.
- **3D ROTATE X** (±180°) — tips the model toward you or away. AUDIO MOD: HIGH-MID.
- **3D ROTATE Y** (±180°) — turns the model about its upright axis. AUDIO MOD: LOW-MID. A slow LFO on ROTATE Y is a turntable; full MOD DEPTH swings a rotation through 180° and the zoom through 200%.
- **Grade** — the same EXPOSURE … HIGHLIGHTS and TINT COLOR / TINT AMOUNT as the video sources.
- **KEY** — the same keyer as the video sources (OFF / CHROMA GREEN / CHROMA BLUE / LUMA BLACK / LUMA WHITE, INVERT KEY, KEY LEVEL, KEY GAIN), so a logo on green or a picture's dark areas can open onto the layers below.
- **MIX** — modulatable, as on every layer.

**About 3D models.** The model is drawn by the graphics card with its own colours and textures, lit simply from the front, on a transparent background, so the layers beneath show around it. While it turns it is drawn at up to twice the picture's size and brought down, for clean edges. Limits: the model is shown as a static object (animations in the file are not played); materials are simplified to base colour, texture and glow; GLB files compressed with Draco or meshopt, and multi-file `.gltf`, are not read. A large model takes a moment to load — the header reads READING… meanwhile — and LOAD ERR means the file could not be read.

A still image is only redrawn when the size changes, so it costs one draw a frame. In Chromium browsers a preset remembers which file was loaded and opens it again (see PRESETS); everything else in the section is saved in every browser.

## 6. Source layers 5–7: SHAPE A, SHAPE B, SHAPE C

Three shape slots which, in the default order, draw on top of the image and video layers, Shape A lowest and Shape C highest. Each slot, top to bottom:

- **MUTE** — silence the slot without changing its settings.
- **Shape dropdown** — pick the shape. The list is in alphabetical order, with **OFF** first, and the names carry their group — **8-BIT :**, **SCENE :**, **SHAPE :** or **VECTOR :** — so each group sits together (every shape belongs to one), with a line across the menu between one group and the next. The closed control shows the name as it is in the list; it no longer puts "SHAPE:" in front. **OFF** draws nothing.
- **BACKGROUND ON/OFF** — OFF (the default) skips that shape's own backdrop fills so only the main geometry is drawn and the layers beneath show through. A few shapes go further and open windows in themselves: SCENE : ALTITUDE drops its sea, SHAPE : TUNNEL leaves the darker half of its bands clear, SHAPE : BLACKHOLE's disc becomes a clear hole, SCENE : WAVY LINES keeps only its bright stripes, SCENE : MAGMA keeps only its glowing melt, SCENE : COASTLINE drops its sand, SCENE : FOREST and SCENE : SKYLINE drop their sky, SHAPE : MURDER OF CROWS draws only its birds and SCENE : CITY drops its asphalt (see the shape notes below). Turn it ON for the shape's full painted backdrop.
- **AUDIO BAND** — which part of the spectrum drives this shape. **ALL BANDS (SHAPE DEFAULT)** keeps the shape's own mapping (bass does one thing, treble another, as described in the shape notes). **BASS**, **LOW-MID**, **HIGH-MID** or **AIR** routes that one band into every reaction the shape has, so a shape that normally spins on the low-mids and flashes on the treble does both on the bass instead. Works for every shape.
- **AUDIO EFFECT** (0–200%) — how strongly the audio drives this shape: 0% holds it still (only the LFOs and its own drift remain), 100% is normal, 200% doubles every reaction. Both AUDIO BAND and AUDIO EFFECT are per slot, so the same shape can be quiet in A and wild in C.
- **DENSITY** — how much stuff the shape draws (particle counts, line counts, ring counts). Per slot, modulatable.
- **RATE OF CHANGE** — speed of that shape's animation. Per slot — each slot runs on its own clock — and modulatable.
- **ZOOM** (1–150%) — the size of the shape on the display, scaled about the centre of the picture. 100% is its normal size; smaller shrinks the whole shape toward the middle — lines, glows and all — and leaves the layers beneath showing around it; larger zooms in and crops. With BACKGROUND ON a shrunken shape stays inside its own frame, a picture within the picture; with BACKGROUND OFF it floats free with no box edge. Per slot and modulatable: the MOD DEPTH / LFO RATE / AUDIO MOD (BASS) group under it lets the shape breathe on an LFO or pump on the kick. At 100% nothing about how the shape draws is changed. Above 100% the shapes drawn as pictures (the 3D scenes, SCENE : MAGMA, SCENE : COASTLINE and the other pixel-buffer shapes) soften slightly, because their picture is enlarged rather than redrawn larger. GLITCH works by shuffling strips of the layers beneath it, so zooming it scales a copy of those layers along with it.
- **TINT** (Shape A, B and C) — colours the whole shape with one colour. All the way left is OFF. The short grey stretch after it makes the shape black and white. The rest of the slider runs once round the colours, red through orange, yellow, green, cyan, blue, violet and magenta back to red; the readout names the colour. The shape keeps its own light and dark and takes the chosen colour in place of its own (as Colorize does in Photoshop), so black stays black and white stays white. It is applied to that shape's layer only, before it is mixed in, and is saved in presets with the other sliders.
- **BLEND MODE** (every layer with a MIX: the camera, both video files, the image and the three shapes; it sits just above MIX) — how the layer is combined with the layers below it, with Photoshop's modes under Photoshop's names and in its groups: NORMAL (the default); DARKEN, MULTIPLY, COLOR BURN; LIGHTEN, SCREEN, COLOR DODGE, LINEAR DODGE (ADD); OVERLAY, SOFT LIGHT, HARD LIGHT; DIFFERENCE, EXCLUSION; HUE, SATURATION, COLOR, LUMINOSITY. **NORMAL** is how the layer has always been laid in — a shape draws itself straight into the picture, with the palette's own blend where it uses one — and costs nothing extra. MIX is the layer's opacity in every mode. Photoshop's DISSOLVE, LINEAR BURN, VIVID LIGHT, LINEAR LIGHT, PIN LIGHT, HARD MIX, SUBTRACT, DIVIDE, DARKER COLOR and LIGHTER COLOR are not offered: browsers have no such blends. The text layer has no MIX and no blend mode. A layer set to anything but NORMAL, or a shape with a TINT, is drawn on its own first and then laid in, which costs a few copies of the picture for each such layer; a shape with BACKGROUND ON blends its backdrop along with it, so turn BACKGROUND OFF to blend the shape alone. Blend modes are saved in presets; older presets load with NORMAL everywhere.
- **MIX** — the slot's opacity over what is beneath it. Shape A defaults to 100%, B and C to 0%, so a fresh session shows one shape. Modulatable.

The same shape can sit in more than one slot: each slot keeps its own copy of the shape's internal state, its own seed and its own time offset, so the copies never move in lockstep.

Number keys 1–9 and 0 pick Shape A from the first ten entries of the list (see the keyboard table).

### WebGL-visualizer set
Five shapes in the spirit of browser music visualizers, drawn in plain 2D. All five keep their own state per slot, integrate their motion from time (so RATE OF CHANGE and PAUSE apply) and draw no backdrop, so they are transparent with BACKGROUND OFF and work as overlays.
- **VECTOR : MESH GRID** — a wireframe plane seen from a low, slowly yawing camera. Rings ripple out from the centre, the spectrum is laid along the radius (bass in the middle, treble at the rim), noise rolls across the whole sheet and every bass onset sends one extra crest outward. Bass raises the peaks, low-mids speed the ripple, high-mids stir the noise; the lines whiten at the crests. DENSITY sets the grid resolution.
- **VECTOR : UNKNOWN PLEASURES** — stacked oscilloscope traces. The live waveform is written into a short history and each line shows an older copy, so a hit rolls back through the stack like a ripple in time; a ridge in the middle, lifted by the spectrum, shapes every trace. Front lines hide the ones behind them (that occlusion is skipped with BACKGROUND OFF, so the layers beneath show through the whole stack). Bass raises the ridge, low-mids sharpen the trace, treble brightens the front lines. With no input it draws a synthetic wave. DENSITY sets the number of lines (10–36).
- **SHAPE : DOT GRID** — a field of dots breathing in rings from the centre: the spectrum runs along the radius, a slow swell circles outward and every bass onset launches a bright ring that travels to the edge. Dot size and brightness follow the local level; treble whitens the brightest dots. DENSITY sets the pitch of the grid.
- **VECTOR : GLOBAL COORDINATES** (was BLOB) — a thin-lined wireframe ball whose surface is pushed in and out by rolling noise. Bass snaps the whole blob larger and throws spikes out of the noise crests on each kick, low-mids spin and stretch it, high-mids churn the noise and deepen the relief, treble whitens and thickens the front lines and lights the core; the spectrum runs pole to pole as extra relief. The back of the mesh is a faint ghost. DENSITY sets the mesh resolution.
- **VECTOR : GLOBAL LONGITUDE** — the same ball as VECTOR : GLOBAL COORDINATES, drawn with its longitude lines only: the lines that run from pole to pole. It responds to the sound in the same way, and DENSITY sets how many lines there are; each line is drawn with twice the points, so it stays smooth.
- **VECTOR : GLOBAL LATITUDE** — the same ball again, drawn with its latitude lines only: the rings round the axis, stacked from pole to pole. Same response to the sound; DENSITY sets how many rings.

### Generative pattern set
Seven shapes in the spirit of generative pattern studies: simple rules, drawn as lines, dots and small marks, that are orderly in silence and come apart with the sound. All keep their own state per slot and draw little or no backdrop, so they work as overlays.
- **SHAPE : NODE GARDEN** — nodes scattered across the field, each linked to every neighbour inside a radius. Slow noise carries the nodes around, so links form and break and clusters gather and dissolve. Bass widens the linking radius (a kick knits the whole garden together for a moment and sends a bright ring out through the links), high-mids speed the drift, every node swells with its own slice of the spectrum and treble whitens the busiest ones. DENSITY sets the number of nodes.

### Vector set
The fifteen shapes listed with a **VECTOR :** prefix (UNKNOWN PLEASURES, SPIROGRAPH, ASTEROIDS, CHAOS CIRCLES, DIAMOND HOLLOW, GLOBAL COORDINATES, GLOBAL LATITUDE, GLOBAL LONGITUDE, HARMONIC, LISSAJOUS, MESH GRID, MOIRE, NEON CITY, SCOPE, TRIANGLES) are drawn by the graphics card the way a vector monitor draws: every line is the path of a beam across the phosphor, with a fine bright core that burns toward white and a soft glow round it, and its light is added to whatever is already there, so crossings and dense places are brighter. Each line is worked out for every pixel, so it is as smooth at a shallow slant as upright and a curve has no beads at its joins, at any window size. What each shape draws, how it moves and how it answers the sound are unchanged; so are its colours and its DENSITY.
- What a beam cannot draw is left out or drawn as a beam would draw it: a filled dot becomes a spot of light, a filled area becomes its outline (SCOPE's bars), and soft glows behind the lines (the core glow of the GLOBAL shapes, SCOPE's wide beam halo and filled area) are dropped. A line's weight still follows the sound, but within a narrower range, as a beam's does.
- A backdrop that fills the whole picture (ASTEROIDS' black sky, NEON CITY's dusk) is still painted behind the lines, and still goes with BACKGROUND OFF.
- The lines are light, so over other layers they add to what is beneath instead of covering it.
- VECTOR : UNKNOWN PLEASURES used to paint each line's ground dark to hide the lines behind it. A beam cannot do that, so the hiding is worked out instead: only the part of each line that stands above the lines in front of it is drawn. With BACKGROUND OFF nothing is hidden, as before, and the lines cross.
- In a browser without WebGL these shapes are drawn as they were before.

### Newer shapes

- **VECTOR : TRIANGLES** (was MATRIX) — after John Whitney's *Matrix III* (1972). A troupe of identical polygon outlines (hexagons on most seeds, sometimes triangles or squares) is spread around a circular or Lissajous orbit by "differential" phasing: copy *i* sits at phase *i* × step along the path, and the step drifts slowly, so the troupe keeps locking into perfect n-fold symmetry and dissolving out of it. Copies are graded in size and each carries nested, shrinking outlines that lag slightly behind it — the film's hexagons within hexagons. Some seeds add a mirrored second troupe. Lines are additive white with palette tints on the inner rings, so it works well as an overlay. Bass swells the orbit and adds rings, low-mids drive the phase, treble brightens the lines. DENSITY sets the number of copies (5–18) and nested rings.
- **VECTOR : HARMONIC** — Whitney's vertical line and dot fields. An evenly spaced row of strokes is bent sideways and lifted by sines of the same drifting phase step, so the row folds, bunches at the folds and spreads again. Stroke length follows the live spectrum across the row; when the music is quiet the strokes collapse to dots. On about half the seeds, high DENSITY switches to a dense full-height coloured curtain, like the film's colour passages. Bass stretches the strokes, low-mids drive the motion, treble whitens them. DENSITY sets the number of strokes (8–60). Draws only lines, so it is transparent with BACKGROUND OFF.
- **SCENE : VAPORWAVE** — a flight over a neon grid toward a striped sun, between ranges of faceted mountains, rebuilt on the 3D engine at the full size of the picture. The floor is black glass ruled with lines of light, and it is a mirror: the sun lies in it, and the sky and mountains stand in it upside down, more clearly the more nearly it is seen along its surface. The floor is also the sound: frequency runs across it from a calm lane down the middle out to both sides, and time runs away from the camera, so every sound rises as a ridge at your feet and travels off toward the horizon (some seeds put the bass at the edges). Where the floor carries sound its lines burn toward white and, on most seeds, the squares under them glow. The mountains are low-poly: flat triangular faces of dark chrome that mirror the sky, every edge a line of neon. Low over the horizon stands the sun, shading from one colour at the top to another at the bottom and cut by dark bars that widen downward and drift, with a glow round it; above are stars, and everything bright flares into the lens. The seed picks one of three scenes — night, dusk or a pastel day — whether the sun is up, its size, the camera height, and which palette colours go to the grid, the mountains, the hot lines, the sun and the sky; the horizon always leans toward magenta. Bass pulses the lines, the horizon and the sun and drives the flight on; low-mids raise the mountains; treble pumps their neon edges. The grid reads the analyser spectrum directly in 32 bands. DENSITY makes the grid finer and the mountains more finely faceted and more numerous, and adds stars and bars to the sun. With BACKGROUND OFF the sky is left clear (the sun stays). Without WebGL it falls back to its earlier line drawing.
- **SCENE : WAVY LINES** (was MEMORY) — a warped field of soft flowing stripes, bent by a swirl about a pinch point. Bass tightens the swirl, low-mids push the stripes along, highs sharpen the stripe edges. DENSITY raises the stripe frequency. With BACKGROUND OFF only the bright stripes remain. (The sheet of thin lines that lay over the stripes has been removed.)
- **SHAPE : ODYSSEY** (replaces WOBBLE) — light in a lens, rebuilt on the 3D engine. A bright light wanders across the picture, with one or two fainter ones at higher DENSITY, and the lens does to it what a lens does: a glow about the light; a long streak through it from side to side, as a wide-screen lens makes; a star of thin rays, slowly turning; a faint ring of colours round it; and the ghosts — pale discs and rings the shape of the lens's six-bladed aperture, strung along the line from the light through the middle of the picture to the far side, each a different size and colour and edged with colour where the glass splits the light. Behind are the blurred discs of lights out of focus (bokeh), large and small, drifting; and from the edges of the frame come light leaks, soft washes of warm colour that swell and ebb. Bass brightens the lights and swells the leaks, and each hit flares everything; low-mids lengthen the streak and carry the lights about; each ghost follows its own band; treble sharpens the rays and makes the blurred discs glint. DENSITY sets how many blurred discs and ghosts there are and brings in the second and third lights. The colours are the palette's. With BACKGROUND OFF only the light is drawn. (The ribbons of light of the earlier version are gone; it is kept as the fallback without WebGL.)
- **SHAPE : BLACKHOLE** (replaces ECHO) — a star-filled black disc with a bright rim, wrapped in stacked polar blobs whose lobes are the spectrum folded around the circle, and thin wobbling orbit loops. Each blob layer also throws one large wing on its own band; bass breathes the disc. DENSITY adds blob layers, orbits and stars. (The crown of straight radial rays and the curtains of waves down the left and right edges have been removed.) With BACKGROUND OFF the centre of the disc is a clear window onto whatever is underneath (Shape A or video), with only the rim and a few inner stars drawn over it.
- **VECTOR : NEON CITY** — a dense wireframe vector city in true 3D. The camera glides quickly and smoothly (no bob) down a boulevard between deep blocks of towers, ziggurats, spired towers, wedges, drum towers and bridged slabs, all drawn purely in lines with a hand-drawn feel (edges of varying pen weight, some missing or doubled), plus floor hatching, mullions, bracing, mast lattices, glowing neon outlines, sagging cables with lamps, and braced gantries with chasing lights. Dart-shaped ships and drones move at their own pace regardless of the camera. Bass surges the edge glow and speed, mids add traffic, treble flickers the neon. DENSITY controls block depth and count, how many edges and details are drawn, gantries, cables and traffic.
- **SHAPE : AMOEBAS** — amoebae under the microscope, rebuilt on the 3D engine at the full size of the picture. The animals crawl as before — each puts out pseudopods, flows into them and draws the rest of itself after, and they nudge one another apart — but they are now shown the way a microscope shows a living cell: as a clear bag of jelly, seen by how thick it is. Each cell is a low dome with a steep edge, denser where it is deeper, and its relief is brought out as an interference microscope does it, every slope lit on one side and shaded on the other, so the cell, its nucleus, each granule and each vacuole stand up from the slide. The membrane is a fine bright line. Inside there is clear jelly at the rim and in the pseudopods; within that the grainy endoplasm, its granules streaming toward whichever pseudopod is leading; the nucleus with its nucleolus; the contractile vacuole, a clear bubble that swells slowly and empties at once; and food vacuoles with coloured contents. Around the cells are bacteria, drifting specks and the blurred rings of out-of-focus dust, and the field darkens toward its edge. Bass pushes the pseudopods out faster and each hit shakes the membranes; mids speed the wandering; treble stirs the granules. DENSITY sets how many amoebae there are (3 to 14, larger than before) and how much else is in the water. Each cell takes a palette colour. With BACKGROUND OFF only the cells are drawn. Without WebGL it falls back to its earlier flat drawing.
- **SHAPE : SNOW** — a snowstorm in SHAPE : RAIN's perspective volume, now drawn by the graphics card: each flake is a soft white puff with an uneven edge, a little brighter above than below, most small and deep in the volume with a few big ones drifting past close to the camera, tumbling down through a wind that wanders slowly on its own and gusts up with the bass. Sizes are as they were. Bass drives the gusts and the fall speed, mids swirl the flakes, treble brightens them. DENSITY sets the number of flakes (140 to 2,240). No floor and no backdrop: it draws over whatever is beneath. Without WebGL it falls back to its earlier discs.
- **VECTOR : SPIROGRAPH** — the drawing toy, drawn flat (it was a turning 3D knot). A toothed wheel rolls round the inside of a toothed ring — on some seeds round the outside — with a pen through one of the holes in the wheel, and the pen's path is the figure. The tooth counts are those of the real set (rings of 96 and 105 teeth, wheels from 24 to 84), so the figures are the real ones: stars, rosettes, woven bands and nets of loops. The figure is drawn as the toy draws it: the pen travels, the line grows behind it, and the ring and wheel are shown faintly, turning. When every pass is finished the pen goes round again in the next colours. The SEED chooses the ring, the wheel, the hole and how the passes are laid over one another — the pen moved hole by hole toward the wheel's centre, the ring turned a little between passes, a different wheel for every pass, or hole and turn together so the figure twists — so every reseed starts a different figure from a clean sheet. Low-mids drive the pen. Each pass listens to one band and the line keeps the weight it was drawn with, so a loud passage stays on the paper as a heavier stretch of line; bass swells all the lines together and a hit flares the pen; treble lights the ring and wheel. DENSITY sets the number of passes (one to six). The ring and wheel are the shape's background: with BACKGROUND OFF they are not drawn, leaving only the figure and the pen.
- **SHAPE : SCRATCH** — scratches, as on a strip of film or the back of a painted pane. Nothing is drawn until the sound asks for it: each bass hit drags one long scratch across the frame, and (from about a third of the DENSITY slider up) a treble or mid transient leaves a short one. A scratch is a single quick movement of the hand — it lands, runs in a slow arc with a little tremor, often ends in a hook, and thins out as the point lifts; the pressure wavers along it so the line swells, narrows and skips, and some have a fainter hairline running alongside. It is drawn in a fraction of a second and then fades. DENSITY also sets how many may be on screen at once; a harder hit makes a longer, slightly heavier scratch. Draws only thin lines, so it works well as an overlay.
- **SCENE : CITY** — an isometric pixel-art city on an endless grid, scrolling past, drawn at twice its earlier resolution (416 pixels wide). No two neighbouring blocks are built alike: building blocks come as four lots, slabs, a large building ringed by little ones or a street of houses with gardens, and a building may be an office, a glass tower, a brick apartment house, a stepped stone tower, a shop with a striped awning, a house with a pitched roof or a warehouse, each with its own wall colour, height, share of lit windows and roof furniture; there are tower blocks, parks (a wood, a lawn round a pond, a formal garden, a sports ground or a playground, each on its own shade of grass) and squares with a fountain, a monument or a market of striped umbrellas. Traffic is cars, taxis, vans, buses and lorries. DENSITY raises the buildings, fills the empty lots, thickens the parks and adds traffic lanes; bass speeds the scroll and the traffic and makes cars hop, mids brighten windows, signs and paint, highs flare the headlights. With BACKGROUND OFF the asphalt is left clear.

### 8-bit set
Five shapes in the spirit of early home-console graphics, listed in the dropdown with an **8-BIT** prefix (8-BIT : RIVER RUN, 8-BIT : SPRITES, 8-BIT : MUNCH, 8-BIT : BREAKOUT, 8-BIT : QUILT): a coarse grid of wide, hard-edged pixels, half-screen patterns mirrored onto the other half, one colour per band of rows, five fixed brightness steps and motion in whole-pixel jumps. With BACKGROUND OFF each draws only its blocks — everything around them is transparent (8-BIT : RIVER RUN's dim colour bands are its only backdrop, and they are dropped).
- **8-BIT : RIVER RUN** (was 8-BIT PLAYFIELD) — a half-screen block pattern, mirrored (or sometimes repeated) onto the other half, held for a few rows at a time and scrolling downward in whole rows with a new colour per band. The spectrum runs down the screen, bass at the top, and sets how far each row reaches out from the centre line; the outermost block of every row is bright, so the outline is a blocky mirrored spectrum. Low-mids drive the scroll, bass hits shift the colours. DENSITY makes the blocks smaller (10 to 32 per half-screen).
- **8-BIT : SPRITES** — ranks of generated 8×8 mirror-symmetric creatures, a different colour on every sprite line, marching sideways in pixel steps with a two-frame walk. Each rank belongs to one band, which hops it upward and switches it to double-width pixels when loud. Bass hits advance the march and every eighth hit breeds a new set of creatures. DENSITY adds ranks and copies. (The shots that the highs fired up the screen have been removed.)
- **8-BIT : MUNCH** — munching squares. Every cell computes a number from its coordinates (x XOR y and two relatives) and that number picks a slice of the spectrum; the cell lights, in three brightness steps, when its slice is sounding, so the carpet of nested squares is the spectrum folded through XOR. A sweeping diagonal stays lit in silence, bass hits advance the phase and every eighth hit swaps the operator. The grid is folded four ways about the centre. DENSITY steps the grid from 16 to 64 cells across.
- **8-BIT : BREAKOUT** (was 8-BIT PADDLES) — a wall of bricks hangs from the top, one colour per row, each column as deep as its slice of the spectrum is loud. Square balls with stepped trails rattle between the wall and the foot of the screen, rebounding off whichever bricks are lit at that instant. There is no bat. Bass speeds the balls and kicks them sideways. DENSITY adds balls, brick columns and rows.
- **8-BIT : QUILT** — a one-dimensional cellular automaton, one generation per ring. New generations are born at the centre and push the older ones outward in whole-cell steps, wrapped around the centre with eight-fold symmetry. The spectrum seeds live cells into each new generation, low-mids set how fast generations are born, each ring's brightness follows its band, every eighth bass hit changes the rule (90, 30, 150, 110, 54) and every sixteenth changes the ring geometry (squares, diamonds, hourglass). DENSITY makes the cells smaller (8 to 36 rings to the screen edge).

Notes on existing shapes: HALO has been removed; CONSTELLATION has been removed; VECTOR : SCOPE's trace, fill, bars and dots span the full width of the display; SCENE : ALTITUDE with BACKGROUND OFF makes everything below sea level transparent (and drops the map grid), so the coastline opens and closes as the mids drain the sea; SHAPE : TUNNEL has been rebuilt on the 3D engine as a smooth flight down an endless tube of flowing colour: no panels and no edges, but soft bands and whorls in the palette's colours that wind round the tube and fold back on themselves, the same pattern several times round like a kaleidoscope's, with the tube bending slowly ahead and a light far down it. Bass is the speed (added up from a smoothed bass, so it never jumps) and each hit sends a brightening down the wall; low-mids twist the tube; high-mids make the pattern swim; treble brightens the crests of the bands. DENSITY sets how many times the pattern repeats round the tube (3 to 8) and how fine the bands are. With BACKGROUND OFF the darker half of the bands is left clear, so the layers beneath show through the wall. Without WebGL the earlier tube of flat panels is drawn; SHAPE : PULSES no longer keeps its emitters in a grid — each stands anywhere in the picture and moves somewhere else every time it fires, so the rings rise in different places each time; VECTOR : ASTEROIDS is drawn flat, as on the arcade screen: each rock is a simple uneven outline in one palette colour, drifting on a straight course, turning slowly, coming back in on the far side when it leaves the picture and swelling with its band (DENSITY sets how many, 3 to 45); SHAPE : AURORA's curtains now flow sideways with the sound instead of only growing and shrinking — each listens to one band and runs with it, neighbouring curtains in opposite directions, slowly when quiet and fast when loud, and every bass hit sends them all the other way; SHAPE : ORBS no longer has ring-shaped orbs (every orb is a soft disc); the SHAPE : GLITCH shape no longer has a standing grid of colour tiles behind it — only the torn strips are drawn, each a broken run of tiles thrown sideways for a moment, so the layers beneath show between them; SCENE : COLOR BARS responds to DENSITY (bar count); SHAPE : RAIN is drawn by the graphics card as small clear drops of water, many more than before (up to eighteen times as many at full DENSITY) and a little smaller, each with a dark edge, the sky's light gathered along its lower side and the glint of a light on its upper one; far drops are bright specks. It is still just the drops, over whatever is beneath (bass speeds the fall, mids swell the drops, treble brightens them, DENSITY sets the count, 270 to 5,580; without WebGL it falls back to its earlier dots); SCENE : LANDSCAPE PAINTING has been rewritten with the 3D engine (see the 3D scene set above) and presets that use it still load; SCENE : FOREST, SCENE : SKYLINE and SHAPE : MURDER OF CROWS have been rebuilt as 3D scenes drawn by the graphics card (see the 3D scene set above): the earlier painted SCENE : FOREST (with its snow line and wildflowers), the watercolour SCENE : SKYLINE (with its storm mood, boats and bird flocks) and the glowing particle clouds of SHAPE : MURDER OF CROWS are gone, and presets that use any of the three still load; SCENE : ALTITUDE's map is now drawn by the graphics card at the full size of the picture (up to 2048 pixels wide instead of a 192-pixel grid), with one more octave of terrain detail and thin, smooth contour, coastline and depth lines, every fifth contour heavier (without WebGL it falls back to the old drawing); VECTOR : SPIROGRAPH is one colour throughout — a palette colour picked by the SEED — in shades that run from deep to pale along the curve, instead of a rainbow.

## 7. TEXT OVERLAY — layer 8

The top layer by default. There it draws text over every source, crisp at full resolution, and every effect after it in the stack treats it with the rest of the picture (in the starting order RESOLUTION pixelates it as it always did, and INK leaves it alone). Dragged lower among the layers, the text is mixed into the picture with them instead: the layers above cover it. Dragged below an effect in the panel, it is laid over that effect's result untouched — the way to keep lettering clean over a blurred, ASCII or halftone picture. The text does not rescale for a square or vertical frame; lower SCALE if long lines clip. The section has no mix slider.

- **MUTE** — hides the text without clearing it; the text and all its settings are kept.
- **Text box** — type your text. **Enter** starts a new line; every line is centred on its own and the whole block stays centred on the Y POSITION. Text is uppercase.
- **FONT STYLE** — LED (5×7 dot matrix), SPACE (thin sans), BOLD (heavy sans with drop shadow), MONO (monospace).
- **SCALE** — letter height. Modulatable.
- **Y POSITION** — vertical position of the text block, 10–90% of the screen.
- **SCATTER FX** — letters (or dots/segments) drift apart. Modulatable.
- **ROTATE FX** — the block spins around its centre. Modulatable.
- **PULSE FX** — per-letter brightness flicker. Modulatable.
- **SCAN LINES FX** — rows of the text drop out in a rolling scan pattern. Modulatable.

Colours come from the current palette.

## 8. EFFECTS

Seventeen effects, each in its own box in the stack (amber edge, marked EFFECT, current value in the title). An effect acts on everything before it in the stack — the whole picture in the starting order, or only the layers above it in the panel once you drag it up among them (see **Stack order** in section 2). They are listed here in their starting order, which is the order the chain applies them until you change it. All seventeen sliders are modulatable (the FEEDBACK KEY controls are not). TRAILS, FEEDBACK and PAINT keep a memory of what they have seen; moving anything in the stack restarts the first two.

RESOLUTION and INK work on the shape buffer. Directly after the first run of layers they are applied there, at full sharpness. Moved anywhere else, they work on a buffer-sized copy of the picture so far, so effects before them lose a little sharpness. (PRESSURE and STATIC have been removed; presets that used them still load, with those two settings ignored.)
- **RESOLUTION** (default 100%, formerly FIDELITY) — the master "image quality" control. Low values pixelate the picture, posterise the colours, add colour fringing and heavy scan lines, and also drop the internal render resolution; high values are sharp and clean. The shapes are drawn 512, 768, 1024 or 1536 pixels wide as the slider rises and 2048 pixels wide at 100% (never wider than the window); the readout shows the percentage and the working buffer width. At 100% the posterise and grain pass is switched off entirely. Text overlay follows it. An AUDIO MOD (HIGH-MID) on RESOLUTION is a classic move. In the starting order it acts on the mixed layers, before INK.
- **INK** (formerly COMIC INK) — black ink outlines with flattened colour. It runs after the RESOLUTION downscale, so the ink lines are drawn over the pixelated picture instead of being pixelated with it.
- **RGB** (formerly RGB SPLIT) — horizontal separation of the red, green and blue channels.
- **ASCII** — the RGB-split picture as a grid of characters from a 70-step brightness ramp, coloured by the picture beneath, on the palette background. Character size grows with the slider; the bass brightens the ramp. AUDIO MOD: LOW-MID.
- **FOG** — banks of fog drifting across the picture: three sheets of soft noise sliding past each other over a thin even haze, a little heavier toward the bottom of the frame like ground fog. The fog is lit by the picture itself — in front of something bright it takes on that colour, mixed with a pale tone from the palette — and the same blurred light is added back as a glow, so lamps and bright shapes show through even thick fog. The slider runs from thin drifting wisps through heavy banks to a blanket in which only the lights show; bass thickens the fog a little and moves it faster. By default sits after ASCII, so it drifts over everything so far, and the stages below (TRAILS, GLITCH, PAINT …) work on the fogged picture. AUDIO MOD: BASS.
- **TRAILS** — persistence; the previous frames linger. Sits here, before GLITCH, so the effects that follow work on the smeared picture. The range was halved: 100% on the slider is a long smear rather than a near-freeze, and modulation can't push it past that.
- **GLITCH** — beat-triggered picture faults. Each detected bass onset rolls the dice: whether to glitch at all, for how long (a few frames up to about half a second), how hard, and which faults are in the burst — slice tearing that wraps around the frame, scattered and stretched blocks, vertical roll, a wide red/blue colour-plane split, frame stutter, mirrored bands, mosaic bands and inverted bars. The layout is re-rolled every one to four frames inside a burst, louder hits glitch harder, and a beat landing mid-burst sometimes just extends it. The slider scales the odds, the length and the violence; at low settings many beats pass clean. With no audio running, bursts arrive at random intervals instead (more often as the slider goes up).
- **PAINT** (formerly PAINT BRUSH) — repaints the picture as a hand-painted work: a field of oil brush strokes that follow the image. A coarse layer of fat strokes blocks in the picture; a fine layer of small strokes appears only along edges; a canvas weave is laid over the top. Strokes run along the edges of the picture and, in flat areas, along a slow swirl. Every stroke has its own character — its own brush load (width), opacity, curvature and chroma, and one of five behaviours: **flat** (some with bristle hairlines through the body), **tapered** (fat to thin as the brush lifts), **dab** (a short fat touch), **dry brush** (three thin streaks with canvas showing between) and **broken** (two slightly disagreeing strokes laid over each other). Some flat and tapered strokes carry a lit ridge of raised paint along one side.
  - The painting is meant to be calm. A stroke, once laid, stays exactly as it is until the picture changes underneath it; only then is a new stroke painted there, on top of the old one. The paint canvas is never wiped, so a still picture holds perfectly still (and costs no brush strokes at all) and a moving one reworks itself like wet paint being pushed around instead of being redrawn. The view's slow breathing zoom and occasional frame jump are applied to the finished painting, so they do not disturb the strokes.
  - The slider fades the painting in over roughly its first two-thirds; the rest loosens the brush a little (fewer, fatter strokes; a looser brush applies to strokes painted from then on). The stroke positions are fixed, so LFO or audio modulation of the amount never shuffles them. Sits between GLITCH and POINTS in the chain, so the strokes are stippled, treated, blurred and fed back like everything else. Saved in presets.
- **POINTS** — redraws the picture as a stippling: small points placed wherever a shape or the image has something to show, and only there — not on a grid. The frame is analysed in small cells and each earns points in proportion to how bright it is and, much more, to how strong an edge runs through it, so contours pick up a dense chain of points while flat lit areas get a sparse fill and dark areas (the backdrop included) get nothing. Point positions are seeded per cell, so the stipple holds still while the picture moves through it rather than flickering. Points take the colour of the picture beneath them (dim cells get a mild lift), edge points are a little larger, and the bass swells them all (the AUDIO MOD here listens to the bass band). The slider sets the scale, from fine dense stippling to coarse sparse points.
  - The slider sets the pitch: low is a fine, dense screen, high is wide spacing with fat dots. The first ~15% of travel fades the dots in over the untouched picture, so a small LFO or AUDIO MOD on a low setting breathes the screen in and out. Sits after PAINT in the chain, so the painted picture is stippled and the dot field is then treated, blurred and fed back. Saved in presets.
- **Picture treatments** — six treatments in the spirit of WebGPU retro-effect tools, by default applied in this order after POINTS and before BLUR. While they sit together in this order they share one analysis: the frame is shrunk to a working buffer no wider than 640 pixels (so they cost the same at any window size) and each runs on it in turn; one moved out of order gets a pass of its own; HALFTONE reads the result and draws its dots at full resolution. Every slider fades its treatment in over its first quarter and then drives its character; the group is skipped entirely when all six are at zero. Each has the usual MOD DEPTH / LFO RATE / AUDIO MOD group.
  - **THRESHOLD** — cuts the picture to two tones (palette background and white). The cut level rises with the slider; the bass nudges it. AUDIO MOD: BASS.
  - **EDGES** — Sobel edge detection in the picture's own colours. The first quarter lays the edges over the picture; the rest fades the picture out and whitens the edges until only glowing outlines remain. AUDIO MOD: HIGH-MID.
  - **CONTOUR** — topographic lines. Brightness is smoothed and quantised into bands (4–16, more as the slider rises, plus a couple on the bass) and a line in a palette colour is drawn wherever the band changes; the picture beneath fades to a dark wash. AUDIO MOD: LOW-MID.
  - **SMEAR** — runs of pixels brighter than a threshold are sorted by brightness along each row, so bright areas smear into streaks. The threshold falls as the slider rises (longer runs) and the bass pulls it lower; past halfway the streaks run vertically. AUDIO MOD: BASS.
  - **DITHER** — ordered (Bayer 8×8) dithering to a 1-bit screen per channel, dark tone from the palette background, in blocks that grow from 1 to 6 buffer pixels with the slider. AUDIO MOD: HIGH-MID.
  - **HALFTONE** — a grid of dots on the palette background, each sized by the brightness of its cell and coloured by it. The pitch widens with the slider; the bass fattens the dots. AUDIO MOD: BASS.
- **BLUR** — softens the whole picture.
- **FEEDBACK** (0–200%) — analog video feedback. The output is fed back into itself, zoomed and rotated a little each pass. Above 100% the loop regenerates and blooms; keep it below 100% for controlled tunnels.
  - **FEEDBACK KEY** — a key section modelled on a video mixer (Roland V-4EX style). **OFF** is the normal additive loop. With a key selected the loop works like a mixer feeding back on itself: the live picture is the foreground, the chosen colour or brightness is cut out of it, and the zoomed and rotated previous output shows through the hole. **CHROMA GREEN** and **CHROMA BLUE** cut out that colour; **LUMA BLACK** and **LUMA WHITE** cut out dark or bright areas.
  - **KEY LEVEL** — how much is keyed out: low cuts only the pure key colour, high cuts a wide range around it.
  - **KEY GAIN** — the edge of the key: low is soft and semi-transparent, high is a hard cut.
  - With a key on, the FEEDBACK slider sets how long the loop persists (at 100% and above the keyed areas never fade). CHROMA GREEN pairs with BACKGROUND → GREEN SCREEN; LUMA BLACK works with the ordinary dark palette backgrounds. Soft glows over a green screen spill a little green into the loop — raise KEY LEVEL to clean it up. The key needs canvas-filter support in the browser; without it the loop stays additive. The key choice and both sliders are saved in presets.

## 9. DISPLAY FILTER

Whole-picture film and video looks, applied to the finished frame after the whole stack and just before OUTPUT GRADE — so dust, static, tape wobble and tint land on top of text, trails and the feedback loop the way a real film or tape transfer would. The panel sits in the same place in the chain: below the stack, above the palette and OUTPUT GRADE. It cannot be moved.
- **NONE**
- **OLD PHOTO** — warm sepia tint, desaturation, slight softening, flicker, gate weave, dust specks, stains and a warm vignette.
- **16MM FILM** — heavy grain, gate weave, dust, warm tint. No flicker.
- **35MM FILM** — fine grain, gentle weave, less dust, near-neutral tint. No flicker.
- **VHS TAPE** — row wobble, colour-channel offset, desaturation, flicker, warm tint, heavier scan lines. No static or noise.

(CABLE TV has been removed; presets that used it load NONE.)

**FILTER LEVEL** sets the intensity of the selected filter and is modulatable. It now scales every part of the look — tint, desaturation, softening, wobble, colour offset, block noise, static, grain, dust and vignette — so a low level is a light touch of the filter rather than a full filter with less grain.

The filter runs on the GPU at full output resolution, so it costs about the same at any RESOLUTION setting; the noise, dust and static keep the pixel size of the working buffer, so they still read as film grain rather than screen noise.

## 10. OUTPUT GRADE

A colour grade applied to the finished frame, after every other effect, so it colours everything: shapes, video, text, trails and feedback. Screenshots, recordings and the virtual camera all include it.

- **EXPOSURE** — ±2 EV.
- **TEMPERATURE** — cool (blue) to warm (amber).
- **SATURATION** — 0% (mono) to 200%.
- **SHADOWS / MIDTONES / HIGHLIGHTS** — lift or crush each part of the tone curve.
- **TINT COLOR** — hue of a colour tint, 0–360° (red, yellow, green, cyan, blue, magenta, back to red). The readout takes on the chosen colour.
- **TINT AMOUNT** — 0–100%, how strongly the output is pushed toward the tint colour. Low values shift the colour without darkening the picture; 100% acts like a full colour gel.
- **RESET GRADE** — all eight back to neutral.

The same eight controls appear as per-source grades in CAMERA, VIDEO FILE A / B and IMAGE, but those affect only their own layer before mixing; this one affects the whole output. All eight are saved in presets.

## 11. COLOR PALETTE and BACKGROUND

- **Swatches** — click any palette. Shape colours, text colours and the default background all come from it.
- **AUDIO PALETTE** — on every detected beat, jump to a random palette. Turns the mic on if needed.
- **INVERT** — inverts all rendered colours.
- **BACKGROUND** (its own section, below OUTPUT GRADE) — PALETTE (the palette's own background colour), or an exact **BLACK**, **WHITE** or **GREEN SCREEN** underneath every layer. GREEN SCREEN is pure #00ff00 so it stays keyable in another app.

## 12. AUDIO INPUT

The section header reads **OFF** until an input is running, then shows the sensitivity percentage.

- **MIC ON/OFF** — turns the audio input on or off (it was in TRANSPORT before). Recording, BEAT RESEED, AUDIO PALETTE and GRANULAR RESET turn it on for you when needed.
- **Slider** — overall audio sensitivity. It scales all the band levels and the beat detector. Each shape slot can further scale or re-route this with its own AUDIO BAND and AUDIO EFFECT controls.
- **Device selector** — choose the input. To react to music playing on the computer rather than a mic, set a loopback/virtual audio device as the input (BlackHole on macOS, VB-Cable or Stereo Mix on Windows).
- **Band meters** — Sub/Bass, Low Mid, High Mid, High/Air. These are the four bands the AUDIO MOD sliders and the shapes listen to. Each band auto-levels so quiet sources still use the full range.

The input is captured raw (no echo cancellation, noise suppression or auto gain) so the visuals see the real signal.

## 13. EXPORT

**SCREENSHOT** — saves the current frame as a PNG at the picture's on-screen resolution and shape, scan lines included.

**FRAME SHAPE**
- **WINDOW** — the picture fills the window, whatever its shape. Recordings and the virtual camera are a 16:9 cut from its middle.
- **16:9**, **SQUARE**, **VERTICAL** (9:16) — the picture itself takes that shape, centred in the window with black bars around it. Shapes and effects are drawn for that frame, so a vertical video is composed as vertical rather than cut out of a wide one, and recordings, the virtual camera and screenshots all come out in that shape.
- The resolution menu (720P / 1080P / 1440P / 4K) sets the **short side**: at 1080P the export is 1920×1080, 1080×1080 or 1080×1920.
- The frame shape is saved in presets. Changing it restarts TRAILS and FEEDBACK. A recording in progress keeps the shape and size it started with, even if a preset is loaded.

**Record**
- **● START REC / ■ STOP REC** — records to an MP4 file (H.264/AAC where the browser supports it, otherwise AV1 or VP9 in MP4; Firefox writes WebM and the button says so).
- **Length dropdown** — 10 s, 30 s, 1 min, 2 min or ∞. Recording stops and downloads automatically at the limit. Elapsed / max time shows in the section header.
- Recordings are rendered at the chosen FRAME SHAPE and resolution (default 1920×1080), regardless of window size. For the sharpest square or vertical export, make the window tall: the on-screen picture is what gets scaled to the export size.
- Audio is always included: pressing record turns the mic on if it isn't already. If the mic is refused you still get video and the button reads "■ STOP (NO AUDIO)".
- **REC AUDIO LEVEL** — target peak of the saved audio (default 70%, shown as about -3 dB). The recorder auto-levels the input up to this and limits anything louder, so exports come out at normal video loudness. The live analysis path is not affected.
- MIC OFF is blocked while recording; stop the recording first.

**VIRTUAL CAMERA**
Browsers can't register themselves as a webcam device, so this feature gets you as close as a page can:
- **VIRTUAL CAM** floats the live output as a picture-in-picture window — no title bar, always on top, natively sized to the chosen frame shape and resolution. Drag it as large as you like; the browser caps it at your display size.
- To use it as a webcam in Zoom, Discord, Resolume, TouchDesigner, etc.: in **OBS Studio** add a **Window Capture** of that window and press **Start Virtual Camera**, then choose **OBS Virtual Camera** in the other app. One-time setup; after that it's just the VIRTUAL CAM button each session.
- In browsers without picture-in-picture the button falls back to a plain window; press **F** or double-click inside it for a frameless fullscreen picture.

## 14. PRESETS

- **SLOT 1–100** with **SAVE / LOAD** — stored in this browser. Filled slots are marked with •.
- **EXPORT FILE / IMPORT FILE** — download or load a `.json` preset you can keep, share or move between machines.
- A preset captures every slider (all three shapes' density, rate, zoom, mix and audio effect; every layer's mix, grade, tint, key and grain settings; the image size, the 3D model's zoom and rotations, and all their modulators; every effect), the text, Shape A/B/C and their AUDIO BAND choices, filter, palette, background mode, all toggles (mutes including the text overlay's, backgrounds, loops, fill screen, granular, key inverts), the order of the whole stack (layers and effects), both loop ranges, recording length and level, export resolution, frame shape, and the seed. It does not include the play head positions or the audio/camera device choice. A slider the preset does not contain (it was saved before that control existed) goes to its default.
- **Media files.** A preset also remembers which file was loaded in VIDEO FILE A, VIDEO FILE B and IMAGE (still or 3D model), and LOAD opens them again from where they are on disk.
  - This works in Chrome, Edge and other Chromium-based browsers. A web page is not allowed to keep a file's path; those browsers instead hand the page a reusable reference to a file chosen through their own picker, and that is what the preset stores. Safari and Firefox have no such reference: there a preset records only the file's name and you load the file by hand.
  - Only files loaded with this version onward are remembered; re-load the media once and save the preset again.
  - The first time you load a preset after reopening the page, the browser may ask whether the page may read the file. Allow it.
  - If a file has been moved, renamed or deleted, the layer's title shows **FIND** and the file name so you know what to load by hand.
  - An exported `.json` carries only the file names. The references live in the browser that made them, so a preset imported on another machine or browser needs its media picked again.
  - A preset with no media saved leaves whatever is loaded alone.
- Presets saved with the old single-video / crossfade panel still load: the crossfade becomes the Shape A and B mixes, the shared source grade and grain settings are copied to the camera and video A, and SOURCE MIX becomes the camera / video A mixes. Presets saved before the layers could be reordered load the standard order, and those saved before the effects could be moved load with the effects after the layers in their standard order. Presets saved before the shapes had ZOOM load at 100%, and the PRESSURE and STATIC settings in older presets are ignored.

## 15. Signal chain (for the curious)

Background → **the stack**, in the order set in the panel → DISPLAY FILTER (weave / tape wobble, colour offset, softening, tint and flicker, grain, dust and stains, vignette) → OUTPUT GRADE (including TINT) → scan lines.

The stack in its starting order: CAMERA (graded, tinted, keyed, mixed) → VIDEO FILE A → VIDEO FILE B → IMAGE or 3D model (sized, graded, tinted, keyed, mixed) → SHAPE A → SHAPE B → SHAPE C (each at its own DENSITY, RATE, ZOOM, MIX and audio routing) → TEXT OVERLAY → RESOLUTION → INK → RGB → ASCII → FOG → TRAILS → GLITCH → PAINT → POINTS → THRESHOLD → EDGES → CONTOUR → SMEAR → DITHER → HALFTONE → BLUR → FEEDBACK (with optional KEY).

How it is put together: the layers before the first effect are drawn into one buffer, INVERT is applied, and that buffer is laid onto the view. Each effect then works on the view as it stands. Each layer that comes after an effect is drawn into an emptied buffer and laid over the view — shapes with the palette's blend, the sources straight over — so the effects before it never touch it and the ones after it do. An effect at 0% is left out, as if it were not in the stack.

Knowing the order helps. In the starting order FEEDBACK recirculates everything, text and effects included; the DISPLAY FILTER comes after it, so the film or tape look sits on top of the loop rather than being fed back into it; INK is early, so it inks the video and shapes but not the later effects; TRAILS comes before GLITCH, so the glitches, paint, points and picture treatments cut into the smeared picture rather than being smeared themselves; FOG comes before TRAILS, so the fog is smeared, glitched, painted and fed back like the picture under it. Any of that can be changed by dragging. Each source's own KEY happens as that layer is mixed in, so a keyed layer only ever opens onto what is already in the picture. A muted layer is simply skipped at its place in the stack. Two details of the starting order are kept from earlier versions so that old presets look the same: TEXT OVERLAY as the top layer is pixelated by RESOLUTION but not touched by INK.

## 16. Tips

- **Reactive but not chaotic:** put a modest AUDIO MOD (30–50%) on RESOLUTION, TRAILS or RGB rather than on RATE OF CHANGE.
- **Beat-driven cuts:** LOAD VIDEO in deck A → its GRANULAR RESET ON → set LOOP START/END to the interesting part of the clip → raise GRAIN CROSSFADE if the cuts feel too harsh. Load a second clip in deck B with a different loop region and set both decks granular for two independent cutters.
- **Live camera as instrument:** CAMERA ON, its GRANULAR RESET ON, then Shape A MIX low or OFF and a sparse shape in Shape B with BACKGROUND OFF and MIX up.
- **Two-deck mixing:** load clips into VIDEO FILE A and B and put an LFO on deck B's MIX (or AUDIO MOD on it) — B fades over A on its own, and KEY on B cuts holes in it instead.
- **Green-screen compositing:** put green-screen footage in VIDEO FILE B, KEY → CHROMA GREEN, then anything in CAMERA or VIDEO FILE A shows through the hole. Raise KEY LEVEL to clean spill, lower KEY GAIN for softer edges.
- **Keyable output:** BACKGROUND → GREEN SCREEN, all shapes with BACKGROUND OFF (the default), filter NONE, RESOLUTION high.
- **Keyed feedback:** BACKGROUND → GREEN SCREEN, FEEDBACK KEY → CHROMA GREEN, FEEDBACK around 100%. The shapes stay crisp in front while their own history tunnels away behind them instead of washing over them.
- **Windows onto another shape:** put SHAPE : BLACKHOLE, SHAPE : TUNNEL or SCENE : ALTITUDE in Shape B or C with BACKGROUND OFF and its MIX up — the layers beneath show through the disc, the open panels or the sea.
- **Beat-cut chaos:** GLITCH around 40–60% with MIC ON fires on the kick only; add a little AUDIO MOD on GLITCH so louder passages glitch harder and more often.
- **Living painting:** PAINT at 70–100% over a slow shape (SHAPE : AURORA, SCENE : WOODS, SHAPE : JELLYFISH) or a still camera, RATE OF CHANGE low, a touch of TRAILS. Add 20–30% AUDIO MOD on PAINT so the brush loosens on the loud parts and tightens back up in the quiet ones.
- **Stippled drawing:** POINTS around 20–50% over a high-contrast shape (SCENE : LIQUID LIGHT, SHAPE : AMOEBAS, SHAPE : COLOR GELS, SHAPE : ORBS) with a touch of TRAILS and BLUR; add 30–50% AUDIO MOD on POINTS so the stipple coarsens and the dots swell on the kick. Put FEEDBACK under 100% behind it and the dots tunnel away.
- **Terminal look:** ASCII at 30–50% over a video or a slow shape with RESOLUTION high; add 30% AUDIO MOD so the characters swell on the kick. CASSETTE palette gives amber-on-black.
- **Print look:** HALFTONE at 40–60% or DITHER at 20–40% over the camera; a touch of TRAILS softens the screen. THRESHOLD before HALFTONE gives a two-tone poster.
- **Glitch streaks:** SMEAR around 40% with 40–60% AUDIO MOD on it — the streaks lengthen on every bass hit and pull back between them. Push it past 50% for vertical rain.
- **Relief map:** CONTOUR at 40% over a soft shape (SHAPE : AURORA, SCENE : LIQUID LIGHT) draws it as a map; EDGES at 60–80% over a hard one (SHAPE : ORBS, SHAPE : COLOR GELS, SUPERNOVA) leaves glowing outlines.
- **Lo-fi overlay:** put 8-BIT : SPRITES, 8-BIT PADDLES or 8-BIT : QUILT in Shape C with MIX up over a video or a smooth shape in A — only the blocks land on top.
- **Three shapes:** with three slots and per-slot rates, try a slow full-screen shape in A (SHAPE : AURORA, SCENE : LIQUID LIGHT), a mid-speed line shape in B (VECTOR : LISSAJOUS, VECTOR : HARMONIC, VECTOR : MESH GRID) and a fast sparse one in C (SHAPE : SNOW, SHAPE : MURDER OF CROWS, SHAPE : NODE GARDEN) at 40–60% MIX. MUTE lets you drop a layer in and out on cue without touching its mix.
- **Restack on the fly:** drag SHAPE A below VIDEO FILE A and key the video (LUMA BLACK or CHROMA GREEN) so the shape shows through the holes in the clip; or drag TEXT OVERLAY below a sparse shape so the shape passes in front of the lettering.
- **Lights in the fog:** FOG at 40–70% over VECTOR : NEON CITY, SCENE : SKYLINE at night or SHAPE : JELLYFISH — the bright parts glow through while the rest sinks into the bank; 20–30% AUDIO MOD makes the fog roll in on the bass.
- **Birds over a landscape:** SCENE : FOREST or SCENE : SKYLINE in Shape A with BACKGROUND ON, SHAPE : MURDER OF CROWS in Shape B with BACKGROUND OFF and its MIX up — the flock wheels in front of the valley or the towers, and every kick startles it.
- **Picture in picture:** a full-frame shape in Shape A, then in Shape B a shape that paints its own backdrop (SCENE : FOREST, SCENE : SKYLINE, SHAPE : TUNNEL, SCENE : PLANET) with BACKGROUND ON, MIX up and ZOOM around 30–50% — it sits in the middle as a framed inset. Turn its BACKGROUND OFF and the frame goes, leaving the shape floating.
- **Pumping shape:** 20–40% AUDIO MOD (BASS) on a shape's ZOOM makes the whole shape swell on the kick; a slow LFO at low depth keeps it breathing between hits. Negative depth shrinks it on the beat instead.
- **Lava and surf:** SCENE : MAGMA or SCENE : COASTLINE in Shape A with BACKGROUND OFF over a video — only the glowing melt, or the water and foam, land on top of the clip.
- **Corridor under a waveform:** HALLWAY in Shape A, VECTOR : UNKNOWN PLEASURES in Shape B with BACKGROUND OFF and MIX around 70% — the traces ripple over the breathing corridor.
- **Whitney over oil:** SCENE : LIQUID LIGHT in Shape A, VECTOR : TRIANGLES or VECTOR : HARMONIC in Shape B with MIX up — the white line figures float over the slow-moving dyes. A little TRAILS gives the lines the film's phosphor lag.
- **Breathing logo:** load a PNG in IMAGE, SIZE around 40%, KEY → LUMA BLACK (or CHROMA GREEN for a green-backed file), then 20–40% AUDIO MOD (BASS) on SIZE so it pumps on the kick; a slow LFO at low depth keeps it alive between hits.
- **One band, many shapes:** put three shapes in A, B and C and set A's AUDIO BAND to BASS, B's to LOW-MID and C's to AIR — each layer moves to its own part of the mix. AUDIO EFFECT at 150–200% on the treble layer makes the highs sparkle.
- **Still shape, moving effects:** AUDIO EFFECT at 0% on a shape freezes its reactions while the effects keep pumping on the same music.
- **Letterboxed clips:** FILL SCREEN on the deck crops away baked-in black bars, so a mixed bag of 4:3 and widescreen files all fill the frame.
- **Sharp titles over a treated picture:** drag BLUR, ASCII or HALFTONE up the panel to just above TEXT OVERLAY (and above any shape you want kept clean). The effect treats only what is above it in the panel; the text and that shape land on top untouched.
- **Feedback behind, shapes in front:** drag FEEDBACK and TRAILS up to just below a video deck. The clip tunnels and smears on its own while the shapes above it stay crisp.
- **Two looks from one pair:** swap THRESHOLD and HALFTONE, or put BLUR before EDGES instead of after — the order of two effects is often a bigger change than either slider.
- **Vertical video:** FRAME SHAPE → VERTICAL, make the browser window as tall as the screen allows, pick 1080P, then record: a 1080×1920 file composed for the tall frame. SCENE : CATHEDRAL, SCENE : LIMINAL, SHAPE : RAIN, SHAPE : SNOW, SHAPE : JELLYFISH and SCENE : NEO TOKYO suit it well.
- **Turntable:** load a `.glb` or `.usdz` in IMAGE, put a slow LFO at full depth on 3D ROTATE Y, a little AUDIO MOD on 3D ZOOM, and a 3D scene in Shape A behind it. Drag IMAGE below the shapes in the panel to put the model in front of them.
- **City that listens:** SCENE : HIGHWAY or SCENE : NEO TOKYO in Shape A with FOG at 20–30%: the towers rise and their windows light with the music, and the signs glow through the haze.
- **A set in presets:** load the clips and images for each song once, save each look to its own slot (there are 100), and LOAD brings back the media along with the settings.
- **Performing:** DETACH the panel to a second display, F for fullscreen on the main one, and save a few slots to jump between looks with SAVE/LOAD.
- **Better recording audio:** feed a virtual audio device (BlackHole / VB-Cable) instead of a microphone for a clean direct signal.

## 17. Troubleshooting

- **Nothing reacts to sound** — open AUDIO INPUT (its header reads OFF), press MIC ON and allow access; check the device selector; raise the sensitivity slider. The band meters should move. If one shape is still, check its AUDIO EFFECT isn't at 0%.
- **A layer is invisible** — check its MUTE button (red = muted) and its MIX, then its place in the stack: a layer above it at 100% MIX with its background on covers it. Drag it lower in the panel (which is higher in the stack), or turn the covering shape's BACKGROUND OFF.
- **SCENE : MAGMA, SCENE : COASTLINE or any of the 3D scenes (SCENE : FOREST, SCENE : SKYLINE, SHAPE : MURDER OF CROWS, SCENE : NEO TOKYO, SCENE : HIGHWAY, SCENE : OCEAN, SCENE : DUNES, SCENE : CLOUDS, SCENE : UNDERWATER, SCENE : PLANET, SCENE : CATHEDRAL, SCENE : LANDSCAPE PAINTING) shows a note instead of a picture** — the browser has no WebGL (or it is switched off). Turn on hardware acceleration in the browser settings. SCENE : ALTITUDE, SCENE : LIMINAL, SCENE : FLYOVER, SCENE : LIQUID LIGHT, SCENE : WOODS, SHAPE : JELLYFISH, SHAPE : AMOEBAS, SHAPE : MODULAR SYNTH, SHAPE : RINGS, SHAPE : TUNNEL, SHAPE : ODYSSEY, SCENE : VAPORWAVE and the VECTOR : shapes fall back to their older drawings in the same situation. SCENE : FOREST also needs a graphics card that can draw into floating-point textures; on the rare one that cannot, it shows the same note.
- **A 3D scene looks soft** — the graphics card is not keeping up, so the shape has lowered its own working resolution. Lower DENSITY, close other GPU-heavy tabs, or use a smaller window; the picture sharpens again by itself when there is room. ZOOM above 100% also softens these shapes slightly.
- **MIC ERR** — the browser refused the microphone. Check site permissions and that no other app has exclusive use of the device. If the chosen input was unplugged, the selector falls back to the default input; press MIC ON again.
- **A layer title reads FIND and a file name after loading a preset** — the preset's video, image or model could not be opened again: it was moved, renamed or deleted, the browser's permission was refused, or the preset came from another browser or machine. Load the file by hand and save the preset again. In Safari and Firefox presets never reopen media.
- **A 3D model shows LOAD ERR** — the file could not be read. GLB files compressed with Draco or meshopt and multi-file `.gltf` are not supported; re-export as a plain `.glb` or as `.usdz`.
- **A 3D model is slow** — a turning model is drawn at up to twice the picture's size every frame. Lower RESOLUTION a step, or use a model with fewer triangles.
- **An effect seems to do nothing** — check where it sits: an effect only treats what is above it in the panel. Dragged to the very top of the panel it has nothing but the background to work on.
- **Text is cut off at the sides in SQUARE or VERTICAL** — the text does not rescale for the narrower frame; lower its SCALE or break the line with Enter.
- **A square or vertical recording looks soft** — the export is scaled up from the on-screen picture. Make the browser window taller (fullscreen on a tall or rotated display is best).
- **CAMERA ERR** — same as above for the camera; try a different device in the selector.
- **Video won't play** — the browser may not support that codec/container. Re-encode to H.264 MP4 or VP9 WebM.
- **Recording is WebM, not MP4** — the browser (typically Firefox) has no MP4 muxer. Use Chrome, Edge or Safari, or convert afterwards.
- **POPUP BLOCKED** — allow pop-ups for the file so the DETACH panel and virtual camera windows can open.
- **Everything feels slow** — RESOLUTION now defaults to 100%, which draws the shapes 2048 pixels wide: four times the pixels of the 1024 step, and for most shapes four times the work. Lowering RESOLUTION a little (92–99% is 1536 wide, 85–91% is 1024) is the first thing to try. Most effects and the heaviest shapes have been through two profiling passes (large gradients and vignettes painted once and reused, scratch buffers kept in main memory, integer pixel loops, no GPU read-backs in the RESOLUTION chain, SVG channel filters replaced with plain composites), so also make sure you're on the latest file. Then — reduce DENSITY, turn off BLUR and the picture treatments (TRAILS and FEEDBACK keep their memories at a working size no wider than 1280 pixels and PAINT only repaints the strokes whose part of the picture has changed, so those three cost about the same on a 4K or Retina window as on a laptop) (each active one is a pass over a 640-pixel-wide buffer; CONTOUR and SMEAR are the heaviest), or set a shape slot to OFF or 0% MIX (a slot at 0% costs nothing). An effect dragged in among the layers adds one full-screen copy per run of layers after it, which is cheap but not free; effects at 0% cost nothing wherever they sit. Two video decks with grades and keys cost two graded draws a frame, which is cheap on the GPU path. The DISPLAY FILTER is cheap (no per-pixel work at the output resolution) and POINTS stays around a few milliseconds: it stamps its points into a buffer no wider than 960 pixels. PAINT costs the most over a fast-moving picture (every changed area is re-stroked) and almost nothing over a still one; raising its slider makes it cheaper (fewer, fatter strokes). FOG is built on small canvases and costs the same at any window size. The heaviest script-drawn shape at 100% RESOLUTION is SCENE : WAVY LINES. SCENE : MAGMA, SCENE : COASTLINE, SCENE : ALTITUDE, SCENE : FOREST, SCENE : SKYLINE and SHAPE : MURDER OF CROWS are drawn by the graphics card and scale their own working resolution down on slower cards; SCENE : FOREST and SCENE : SKYLINE ask the most of the card. SCENE : FOREST, SCENE : SKYLINE and SCENE : NEO TOKYO rebuild their worlds on a new seed, so BEAT RESEED with any of them will hitch on every kick. SHAPE : MURDER OF CROWS also flies its birds in the page, which costs a little more as DENSITY rises.
- **Old preset loads a different shape** — PLASMA, WOBBLE, LATTICE and ECHO were replaced; presets that used them load SCENE : WAVY LINES, SHAPE : ODYSSEY, SHAPE : ODYSSEY and SHAPE : BLACKHOLE respectively. SUPERNOVA, POLYLOCK, CELL DIVISION, CONSTELLATION, FLOW DOTS, HALLWAY and RESONANCE FIELD were removed later; presets that used them load SHAPE : ODYSSEY, SHAPE : SCATTERED CUBES, SHAPE : AMOEBAS, SHAPE : NODE GARDEN, SHAPE : DOT GRID, SHAPE : TUNNEL and SHAPE : DOT GRID. HALO, SEQUENCER, DANCER, WEB and PIXEL WORLD were removed; presets that used them load SHAPE : RINGS, SHAPE : MODULAR SYNTH, SHAPE : ORBS, SHAPE : TUNNEL and SCENE : VAPORWAVE respectively. WAVY FORM and BASS BALL were renamed VECTOR : UNKNOWN PLEASURES and BLOB (now VECTOR : GLOBAL COORDINATES) and load as such. PLAYFIELD, SPRITES, MUNCH, PADDLES and QUILT only gained their 8-BIT prefix; presets that used them load unchanged.
- **Video shows black bars** — turn on the deck's FILL SCREEN; the bars are part of the file and it zooms past them. A clip that fades fully to black keeps its last measured crop until the picture returns.
- **Old preset is missing PRESSURE or STATIC** — those two effects have been removed; the rest of the preset loads as saved.
- **Old preset looks different** — it was saved with the crossfade panel; see PRESETS for how the old controls map onto the layers. Shape backgrounds now default to OFF and RESOLUTION to 100%, but a preset restores whatever it saved.
- **Presets vanished** — slots (and the remembered media references) live in the browser's storage for that file location; clearing site data or moving the HTML file resets them. Use EXPORT FILE for anything you want to keep.
